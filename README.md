# Projet Boutique Zarabe

Voici notre projet de site e-commerce. On a décidé de faire une boutique qui vend des qamis et des babouches, nommée ZARABE

Pour le code : 
- Le front (l'affichage) est fait en HTML, CSS et du JavaScript basique.
- Le back est fait avec Node.js (Express) pour envoyer les données des produits depuis un fichier data.json.

Les fonctionnalités qu'on a codées :
- Une page d'accueil qui affiche tous les articles automatiquement.
- Une page produit quand on clique sur un article, avec la possibilité de changer la couleur (l'image change en fonction) et choisir une taille.
- On a fait en sorte que tout le site (le front et le back) se lance en même temps avec une seule commande pour que ce soit plus pratique.
- en gros tout ce qui ai demandé pour le tp

## Comment lancer le projet ?

il y a juste deux commandes à taper :

1. Ouvre ton terminal et va dans le dossier backend :
`cd boutiquejs/backend`

2. Lance le serveur :
`node app.js`

Ensuite, tu as juste à ouvrir ton navigateur et aller sur l'adresse : **http://localhost:3000**
Et normalement le site s'affiche direct !
